# Plagiarism Spot-Checker

A single-file, offline web tool for quick originality spot-checks: paste or upload text, and it splits the text into sentences and distinctive phrases, then checks them with exact-phrase web searches and lets you mark each chunk Clear or Flagged before producing a report.

## Use
Open `Plagiarism-Spot-Checker.html` in any modern browser. No installation or account needed. (An internet connection is required for the web searches themselves.)

Note: this is a spot-checker, not a substitute for institutional tools such as Turnitin or iThenticate.
